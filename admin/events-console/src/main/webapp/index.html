Why a selector matters

A consumer whose message selector does not match what the publisher stamps receives nothing — and that looks exactly like no events being published. The selector is a quoted string literal no compiler ever checks. This console derives it from the catalog, generates consumers with it filled in, and reports any live subscription that has drifted.
