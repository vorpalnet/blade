For route templates, not conditions ${previousApp} ${previousState} name the application that just ran. Inside a condition they are constants — always this state — so testing one always matches (or never does) and hides every transition below it. Use them in a Route URI.

Time and sampling ${hour} 0–23, server local ${dayOfWeek} MONDAY…SUNDAY ${hash100} 0–99, stable per call — use for percentage rollout, e.g. ${hash100} < 5 sends 5% of calls this way

Also ${now} ${now:yyyy-MM-dd} ${uuid} a name that resolves to nothing falls back to an environment variable, then a system property, then stays literal

A selector may reuse any of these names to override it. An unresolved ${x} compares as empty and is false in a boolean test.
