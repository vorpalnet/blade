WebRTC Phone

A browser as a first‑class SIP endpoint. This page speaks a small set of JSON events over a WebSocket to the gateway on the engine tier — not SIP — while the network sees an ordinary SIP call. Dial another registered browser and the media runs peer‑to‑peer with no media server at all; dial a phone number and the call is anchored, because a phone cannot speak ICE or DTLS.
