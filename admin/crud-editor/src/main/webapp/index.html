BLADE CRUD Editor

CRUD stands for the four things a rule can do to a SIP message: Create it, Read it, Update it, Delete it — and the "it" can be any part of the message: a header, the Request-URI, or any body content, whether XML, JSON, SDP, or a multipart MIME part. A pipeline decides which rule set each call gets; the rules do the rewriting; a live preview replays every unsaved change against a real message before you save, and long before you publish.
