Five capability areas across three depths. Each demo carries a readiness mark — built, works-with-care, or roadmap — so it's clear what's real. Below the grid: a few suggested sequences, and prep notes for the demos that need one.

The idea under all five pillars

A SIP conversation, written top to bottom like a poem — not scattered across handlers like a choose-your-own-adventure.

This is the reason BLADE exists. Every capability below is quick to build because the development model is simple: one callflow reads start to finish, the call's state carried in the code itself. Any single feature can be matched elsewhere — the way you write them is what's different.

The matrix — Pillar × Altitude

Depth increases downward: Hooks are quick looks, Capability shows the feature genuinely working, Proof is an end-to-end scenario. Boxes with a ↗ open a live demo page — hover to highlight, click to open.

Trust (security logic in the core) and Integrate (open to any third party) look contradictory — and both hold, because BLADE is a development environment, not a finished product. You pick the features you want; integrators build them out.

Known limits & prep

What isn't built yet, and the demos that need a setup step first.

  • Cloud LLMAlice's answers use the cloud Claude API. The two-way agent is live — on-net ASR and TTS run on CPU and the call audio never egresses — but the thinking step sends the transcript text to the Claude API in the cloud. A fully on-net LLM (Gryphon W2) is the roadmap. Say it plainly; Alice does.
  • Not builtMedia node-kill recovery. The media-server reattach handshake is still a TODO — failover isn't shown on the media plane yet.
  • Prep firstOn-net ASR: use clean audio. 8 kHz narrowband degrades ("sales" → "SAILS"); policy-file aliases mitigate it, but don't tempt it live.
  • Prep firstPre-stage the OCCAS install. The one-time eDelivery media fetch needs a manual Oracle license click — run download beforehand so the live run is genuinely one hands-off command. The nft keepalive shield is still the live backstop.
  • Prep firstWake the analytics stack. The Autonomous DB auto-stops after 7 idle days and the OAC dashboard bills while running — spin both up before recording.
